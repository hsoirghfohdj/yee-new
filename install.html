Hold the Classboard button above and drop it onto your bookmarks bar.

Can't drag it?

Copy it in instead.

  1. Click Copy code.
  2. Right-click your bookmarks bar, then pick Add page… (or Add bookmark).
  3. Name it Classboard, paste the code into the URL box, and save.
