  1. Show your bookmarks bar: Ctrl + Shift + B (⌘ + Shift + B on Mac).
  2. Drag the Class Dash button above onto the bookmarks bar.
  3. Open Canvas and click the bookmark. Click it again (or press Esc) to close.

Can't drag it? Copy it instead

  1. Click Copy code.
  2. Right-click the bookmarks bar → Add page… (or Add bookmark).
  3. Name it Class Dash and paste the code into the URL box, then save.
