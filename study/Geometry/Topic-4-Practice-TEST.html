20

Error analysis. In ΔXYZ, XY ≅ XZ and m∠X = 40°. A student wrote:

"Base angles are congruent, so m∠Y = m∠X = 40°.
m∠Z = 180 − 40 − 40 = 100°."

Describe the error and find the correct m∠Y and m∠Z.

Show answer

The base angles are the ones opposite the congruent sides. ∠Z is opposite XY and ∠Y is opposite XZ, so ∠Y ≅ ∠Z. ∠X is the vertex angle and doesn't match either one.

m∠Y = m∠Z = (180 − 40) ÷ 2 = 70°

m∠Y = m∠Z = 70°

C1

Solve for x and y. Then give all three angle measures and classify the triangle. Hint: you'll need a system of equations.

Figure not drawn to scale.

Show answer
Base angles ≅: x + 2y + 20 = 4x + 10 → 2y = 3x − 10 Angle sum: 3y + (x + 2y + 20) + (4x + 10) = 180 5x + 5y + 30 = 180 → x + y = 30 → y = 30 − x Substitute: 2(30 − x) = 3x − 10 60 − 2x = 3x − 10 70 = 5x → x = 14, y = 16

C2

ΔABC has vertices A(−4, 1), B(−1, 5), C(−1, 1). ΔDEF has vertices D(2, −1), E(2, −4), F(6, −4).

  1. Prove the triangles are congruent. Write a congruence statement with the vertices in the correct order, and name the shortcut.
  2. Find m∠A + m∠F without a protractor. Explain.
  3. Classify ΔDEF and find its area.
Show answer
AB = √(3² + 4²) = 5 BC = √(0² + 4²) = 4 AC = √(3² + 0²) = 3 DE = √(0² + 3²) = 3 EF = √(4² + 0²) = 4 DF = √(4² + 3²) = 5

a. Match by length: A is between the 5 and 3 sides, so A ↔ D. B is between 5 and 4, so B ↔ F. C ↔ E. ΔABC ≅ ΔDFE by SSS. (Writing ΔDEF in that order would be wrong.)

b. ∠F ≅ ∠B by CPCTC. ∠C is a right angle (horizontal side meets vertical side), so ∠A + ∠B = 90°. So m∠A + m∠F = 90°.

c. Right angle at E, three different sides: right scalene. Area = ½ · 3 · 4 = 6 units².

C3

ΔACB ≅ ΔDCE, where A, C, D are on one line and B, C, E are on one line. Find x and y, then find m∠B and classify ΔDCE.

Figure not drawn to scale.

Show answer
Vertical angles: x² − 4x = 3x + 8 → x² − 7x − 8 = 0 → (x − 8)(x + 1) = 0 → x = 8 or −1 CPCTC ∠A ≅ ∠D: y² + 2y = 10y − 12 → y² − 8y + 12 = 0 → (y − 2)(y − 6) = 0 → y = 2 or 6 Every root gives a positive angle, so use the triangle sum in ΔDCE: (3x + 8) + (10y − 12) + (15y + 10) = 180 x = 8, y = 6: 32 + 48 + 100 = 180 ✓ x = 8, y = 2: 32 + 8 + 40 = 80 ✗ x = −1, y = 6: 5 + 48 + 100 = 153 ✗ x = −1, y = 2: 5 + 8 + 40 = 53 ✗

So x = 8 and y = 6. m∠E = 15(6) + 10 = 100°, and ∠B ≅ ∠E by CPCTC.

x = 8, y = 6 · m∠B = 100° · obtuse scalene
