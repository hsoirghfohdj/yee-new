Your own Interstellar.

Launch a copy of Interstellar that you host yourself. This page does not load anything from gointerstellar.app. Interstellar's web proxy requires a running server, so it cannot run as a single standalone HTML file inside the game library.

Example: http://localhost:8080 for a locally running copy. Or paste your own HTTPS-hosted Interstellar URL. Addresses are saved only in this browser.
Don't have a server running?

Install the real application from the official open-source repository. On your own computer, with Node.js 22 and Git installed, run:

git clone https://github.com/UseInterstellar/Interstellar.git cd Interstellar npm install npm run start

Then enter http://localhost:8080 above. The source and dependencies are downloaded from GitHub/npm during setup; the running app is served by your own computer. Remote websites still need internet access.
